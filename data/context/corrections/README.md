# Frozen card corrections

This directory stores explicit, human-readable audit records for any pre-grading correction made to an already-frozen Oak weekly card.

A correction record must identify the affected game, the reason for the correction, the exact before/after values, the source frozen-card blob, the code fix that justified the correction, and which model components remained unchanged.

These records do not replace immutable production run archives. They document exceptional corrections to the canonical frozen card before grading.
