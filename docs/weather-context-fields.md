# Live weather context fields

The live preview may include: `weather_available`, `weather_source`, `forecast_time_utc`, `temperature_f`, `wind_mph`, `wind_gust_mph`, `precipitation_probability_pct`, `precipitation_in`, `weather_code`, and `weather_auto_points`, plus schedule metadata such as `roof`, `surface`, and `stadium` when available.

`weather_auto_points` remains fixed at `0.0` in this informational layer.
